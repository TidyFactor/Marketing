## ⚡ Schnellstart (Quickstart)

```bash
# Installation & Direktaufruf via NPX
npx @tidyfactor/cli-marketing
```

Oder direkt in Ihrem KI-Assistenten aufrufen (*Google Antigravity, Claude Code, Cursor, Codex*):
```text
/tidyfactor-marketing
```
